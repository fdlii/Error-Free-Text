Документация по установке и развёртыванию приложения.

## Требования

Для запуска приложения на вашем устройстве должен быть установлен:

- **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** — для контейнеризации и запуска приложения

## Установка и запуск

### Шаг 1. Получение исходного кода

Скачайте архив с проектом с GitHub:

1. Перейдите на страницу репозитория
2. Нажмите кнопку **Code** → **Download ZIP**
3. Распакуйте архив в удобную для вас директорию

Либо клонируйте репозиторий через Git:

```bash
git clone https://github.com/fdlii/Error-Free-Text.git
```

### Шаг 2. Запуск Docker Desktop

Перед сборкой приложения убедитесь, что **Docker Desktop** запущен на вашем устройстве.

### Шаг 3. Сборка и запуск приложения

Откройте командную строку (Terminal / PowerShell / cmd) в корневой папке проекта и выполните команду:

```bash
docker-compose up --build
```

Команда соберёт образ приложения, получит все необходимые зависимости и развернёт приложение в контейнере.

После успешного запуска приложение будет доступно и готово к использованию.

### Остановка приложения

Чтобы остановить приложение, в той же командной строке нажмите `Ctrl + C`, либо в отдельном окне терминала выполните:

```bash
docker-compose down
```
